# AGENTS.md

Bun + Turborepo monorepo (Better-T-Stack): React Router web + Fastify/tRPC server, Drizzle SQLite/Turso, Better-Auth, shared shadcn UI.

## Commands (run from repo root, use `bun`)

- Install: `bun install` (postinstall regenerates Varlock env types)
- Dev: `bun run dev` (all) / `bun run dev:web` / `bun run dev:server`
- Verify: `bun run check-types` (no lint/test suites exist; `lint` in turbo.json has no scripts behind it)
- Build: `bun run build`
- DB (delegate to `@chimera2/db` via turbo): `bun run db:push` / `db:generate` / `db:migrate` / `db:studio` / `bun run db:local` (`turso dev --db-file local.db`)
- Env codegen after editing any `.env.schema`: `bun run env:generate`
- Auth schema after changing auth plugins/options: `bun run auth:generate`, then review diff and apply via drizzle workflow
- Docker: `bun run db:push` first (populates `./.data/local.db` bind-mount), then `bun run docker:build` / `docker:up` / `docker:logs` / `docker:down`
- shadcn: shared primitives from root `npx shadcn@latest add <comp> -c packages/ui`; app-only blocks from `apps/web`

## Env (Varlock, not plain dotenv)

- `bunfig.toml` sets `env = false`: Bun does NOT autoload `.env`. Entry `apps/server/src/env.server.ts` does `import "varlock/auto-load"` then re-exports generated `src/env.ts`. Always `import { ENV } from "./env.server"` (server) or generated `env.ts`, never `process.env` for configured vars.
- `src/env.ts` files are autogenerated (`DO NOT EDIT`); commit `.env.schema`, never secrets.
- `packages/db/.env.schema` has no vars of its own: `# @import(../../apps/server/, pick=[NODE_ENV, DATABASE_*])`. `DATABASE_URL` lives in `apps/server/.env`. Run Varlock-dependent tools from the owning app dir (`varlock run ...`); `drizzle.config.ts` also relies on `varlock/auto-load`.
- Ports: server `3000`, web dev `5173` (docker `3001`). `CORS_ORIGIN` must match the web origin; `BETTER_AUTH_URL` is the server URL.

## Architecture

- `apps/server/src/services.ts` owns the singletons: `db = createDb(ENV)`, `auth = createAuth(ENV, db)`. Packages (`@chimera2/db`, `@chimera2/auth`) export factories (`createDb`, `createAuth`), never read env themselves.
- tRPC: router in `packages/api/src/routers/index.ts`, shared context type in `packages/api/src/context.ts` (`{ db, session }`), Fastify adapter context in `apps/server/src/context.ts` (resolves session via `auth.api.getSession`). New endpoints: add `publicProcedure`/`protectedProcedure` from `@chimera2/api` to the router.
- Auth config in `packages/auth/src/index.ts` (`drizzleAdapter`, sqlite, email+password, cookies `sameSite: none, secure: true`). CLI entry is `apps/server/src/services.ts`, output `packages/db/src/schema/auth.ts`; hand-editing that schema file is overwritten by `auth:generate`.
- Web: React Router v8 + Vite with `varlockVitePlugin`; `check-types` requires `react-router typegen` first (already in the script, do not replace with bare `tsc`).
- UI: tokens in `packages/ui/src/styles/globals.css`, primitives in `packages/ui/src/components/*`; import as `@chimera2/ui/components/<name>`.
- Observability: server uses `evlog` (fastify plugin + `createFsDrain()` in non-production); logs land in `.evlog/logs/` NDJSON.
